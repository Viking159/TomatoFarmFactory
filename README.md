# Tomato Factory Tycoon

A mobile idle/tycoon game developed with Unity.

The project demonstrates production experience in monetization, analytics integration, and maintaining a live application.

## 📱 About the Project

Tomato Factory Tycoon is a casual idle game where the player builds and upgrades a tomato production factory.

The project was developed as an indie release and published on Google Play.
